# Workspace Rules

## Git Workflow
- After completing and verifying any file edits in this repository, always stage the changed files, create a clear commit message, and push to the remote branch (`git push`) automatically without waiting to be asked.
- Verify changes (e.g., `npm run typecheck`, `npm run lint`, and `npm run build` for code changes) before committing and pushing.
- Never commit secrets, `.env` files, or unrelated untracked files.
